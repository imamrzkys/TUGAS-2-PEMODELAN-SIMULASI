Input Parameter

Satuan: menit. Default sesuai soal: antar kedatangan 4 menit, pelayanan 3 menit.

λ = 1 / waktu antar kedatangan
μ = 1 / waktu pelayanan
Simulasi biasanya lebih dekat ke rumus teori (Erlang-C).
Catatan: Halaman “Hitung” tetap menampilkan Rumus Tugas sebagai acuan manual, dan tambahan Rumus Teori sebagai referensi.

Parameter Simulasi

Disarankan ≥ 3000 agar stabil.
Seed sama → hasil simulasi konsisten.
Target laporan: Bandingkan hasil rumus (manual) dengan rata-rata simulasi dan jelaskan selisihnya.

Rumus Tugas

λ = 1 / Tantar μ = 1 / Tlayanan ρ = λ / (2μ) W = 1 / (μ − λ/2) Wq = λ² / (2μ(μ − λ/2))

Rumus di atas dipakai untuk menyamakan hasil web dengan perhitungan manual sesuai lembar tugas.

Tip: untuk pengujian cepat, input (4, 3) harus menghasilkan W=4.8 dan Wq=0.45 pada Rumus Tugas.
